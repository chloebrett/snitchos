### The load-bearing moment

The trace counts lines **manually, four times**, gets it wrong ("This is 85
lines" for a program of roughly 78), and then deletes working code to fit:
*"Remove book function (save 20 lines)"*, *"I will remove one test to save
lines"*, *"I can remove comments"*.

It also counted its own `test` blocks against the size budget, which prompt v2
had not excluded — so the module was squeezed to make room for the tests. Both
defects are fixed in v3: size counted in declarations rather than lines, tests
explicitly excluded, and the range stated as a guide rather than a limit.

Note also the first draft nests `ext needsCooldown` and `ext checkCooldown`
*inside* a `test` block — caught and removed by the model itself in a later pass.
